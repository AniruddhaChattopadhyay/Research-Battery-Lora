## 2. Findings

1. **One interface for all.** All 21 models answer through one endpoint with one request shape. Each response gives the resolved model with a date, for example `typesafe/jev-1.13-20260917`. This is the version string for E7.
2. **The Jev alias already moved.** On OpenRouter, `~typesafe/jev-latest` already resolves to `typesafe/jev-1.14-20261014`. The TypeSafe documents said that `jev-latest` moves "in about one week" from 2026-10-14. `~perplexity/pplx-decider-latest` resolves to `pplx-decider-v1.1-27b-20261006`.
3. **The interfaces have different limits.** This is a result for the paper (taxonomy) and a constraint for the design:

   | System | Limit (from the error messages) |
   |---|---|
   | Respan Span-01, Span-01-lite | Only yes/no (`noul`) questions with plain-string instructions. The input must be a string or a chat transcript. |
   | Together Tev1-4B | 2 to 20 options for each choice question |
   | Upstage Solar Decide, Solar Decide Flash | 26 or fewer options for each choice question ("single-token labels") |
   | ScaleDown Classify-1 | The input must be a string or an object with only `text`, `document` and `document_mime_type` |
   | Jev, OpenAI, Perplexity, Microsoft, Cloudflare and others | Accepted all 4 tasks, including 77 options |

4. **OpenRouter mixes providers.** In one run, OpenRouter sent Clef to PrimeIntellect (16 calls), DeepInfra (3) and Cloudflare (1), and Kev-4B to Phala (13) and SiliconFlow (7). Each provider can serve a model differently.
5. **Jev details.** Jev rounds its probabilities to 0.01. It returns the probabilities of all 77 Banking77 options. The bill counts only input tokens ($0.042 for each 1M).
6. **Latency through OpenRouter from Bangalore.** For most models, p50 is 450 to 1,300 ms. Solar Decide is 8.2 s and Classify-1 is 6.1 s. This is not the E8 protocol, and the network adds time.
7. **Cost.** $0.02 to $0.15 for 1,000 calls of about 1,000 input tokens.

---

## 3. Changes after E0

1. The HelpSteer2 input is now one string ("Prompt: ... Response: ..."). E0 used an object.
2. `src/openrouter.py` pins one provider, with no fallback, for Clef, Clef-flash, Clef-omni (Cloudflare) and Kev-4B (Phala). A test on 2026-10-15 confirmed the pins.
3. Use Banking77 only for the systems that accept more than 26 options. Add a choice task with 20 or fewer options (When2Call has 4).
4. Use the Respan models only on predicate tasks.
